# 侧边栏项目分组（顶部切换 + 拖拽）

## Goal

用户用扁平「项目组」整理多个仓库。桌面顶部像 EnsoAI 一样切「全部 / 某组 / 未分组」，列表仍是置顶 → 项目 → 归档，项目和组头可拖。手机抽屉同一套切片语义，交互简化（只切组、不改组）。没有组时两侧栏与现在一致。

## Background

- 桌面现状：`Sidebar.tsx` + `stores/sessions/pinned.ts` — 置顶跨项目、项目可折叠/手排、归档钉底且按项目再分组。项目无用户分组。
- 手机现状：`packages/phone/src/SessionDrawer.tsx` 复刻置顶 / 项目 / 归档，排序用 `@shared/pair/drawerOrder`；不能加删项目。
- 参照 EnsoAI 扁平组 + `GroupSelector`；不参照 orca 嵌套 / folder-scan / 多 `groupBy`。
- 桌面顶行已是 `NodeSwitcher`。分组选择器必须第二行。
- 拖拽权威：`dragDrop.ts` 的 `routeDrop`（纯函数 + 测试）。

## Confirmed facts

- `Project`（`src/shared/types/project.ts`）无 `groupId`。
- 项目手排 / 置顶手排 / 归档项目 id 在 localStorage（`sidebarOrderStorage.ts`）；`pairCatalog` 订阅后下发。
- 会话切换槽（`sessionSwitchSlots.ts`）按可见置顶 + 未折叠项目编 9 槽。
- 手机 `projects` 帧：`{ type: 'projects'; projects: ProjectEntry[] }`（`packages/pair/src/protocol.ts`）。`slimProjectsForPhone` 剥 `path`。
- 远程节点侧栏只读，无本机拖拽。

## Requirements

### R1 数据（桌面权威）

- 扁平组：`id`、`name`、可选 `emoji`、可选 `color`、`order`。
- 项目可选 `groupId`；缺省 = 未分组。组只挂项目。
- 组目录与 `groupId` 进 settings 持久化。当前选中组、组折叠态走 localStorage（桌面 / 手机各自一份，互不同步）。
- 删组：成员 `groupId` 清空。若桌面正看着该组，回到「全部」。
- 归档项目保留 `groupId`，恢复后回原组。
- 0 个用户组：两侧都不渲染选择器，无「未分组」段头。

### R2 桌面顶部切换

- ≥1 组时，节点行下出现选择器：`全部` | 各用户组 | `未分组`。
- 行内：可选 emoji、色点、名称、数量、chevron。全部 / 未分组无色点。
- 「全部」：按组 `order` 分段，空组也占一段；未分组段在最后（有未入组活跃项目，或拖拽需要落点时）。
- 「某组」/「未分组」：只列该切片。
- 置顶、归档、侧栏搜索、会话切换槽跟当前切片滤；「搜索一切」仍全局。
- 切组不切换当前会话。
- 节点与分组正交。远程无组数据时不显示选择器。

### R3 桌面拖拽

接到现有 `DndContext` + `routeDrop`。

| 拖 | 落到 | 结果 |
|---|---|---|
| 项目 | 同组另一项目 | 组内重排 |
| 项目 | 组头 / 未分组头 / 他组项目行 | 改 `groupId` + 按指示线插入 |
| 项目 | 展开的选择器菜单项 | 改 `groupId` |
| 组头 | 另一组头 | 改组 `order`（仅「全部」） |
| 会话 / 文件 | 组头 | no-op |

- 单组视图无其它组头；跨组走选择器或右键。
- 6px 阈值不变。组头编辑按钮不是 handle。
- 归档项目不能拖进组。

### R4 桌面其它入口

- 建组：选择器在「全部」时的 `+`，或项目右键。对话框：名称 + 可选 emoji/色。
- 项目右键「移到分组」。
- 加项目可选目标组；默认 = 当前组（「全部」→ 未分组）。
- 组头不放「新会话」。组头可折叠该段。
- 搜索命中组名 / 项目名 / 会话标题时对应行可见（搜索中分段展开）。

### R5 手机（同语义、简交互）

- 目录下行：`ProjectEntry.groupId?` + 同帧可选 `groups[]`。旧桌面不发、旧手机忽略未知字段。
- 有 ≥1 组时抽屉顶（「项目」标题行下或替代表题旁）出现选择器，选项与桌面相同。
- 置顶 / 项目列表 / 归档按当前切片滤，规则与桌面 R2 相同。
- 「全部」按组分段展示组头（只读：无拖、无建/改/删/移组）。组头可折叠。
- 切组不切换当前会话；不在切片里时聊天区保持。
- 选中组存在手机本地；与桌面当前组无关。
- 无组或旧桌面：抽屉与现在一致。

### R6 兼容

- 旧 `settings.json` 无组字段即可用。
- 旧手机 + 新桌面：多字段不崩，列表仍扁平（读不到选择器）。
- 新手机 + 旧桌面：无 `groups`，不渲染选择器。

## Out of scope

- 嵌套组、目录扫描自动成组、orca `groupBy`。
- 切组改当前会话。
- 会话拖进组；组当工作区。
- 手机改组（拖 / CRUD / 右键移组）。
- 远程节点编辑对方的组。
- `hideGroups` 设置项。

## Acceptance Criteria

- [ ] **AC1** 无用户组时，桌面侧栏与手机抽屉结构与现网一致。
- [ ] **AC2** 桌面建成 ≥1 组后出现选择器；切「全部 / 该组 / 未分组」时列表、置顶、归档、侧栏搜索、切换槽只含该切片。
- [ ] **AC3** 桌面「全部」按组 order 分段，空组有组头。
- [ ] **AC4** 桌面 / 手机切组都不改变当前打开的会话。
- [ ] **AC5** 桌面项目拖到另一组头或选择器中的组，项目换组；拖到未分组则清空 `groupId`。
- [ ] **AC6** 同组内拖项目只改手排。
- [ ] **AC7** 「全部」下拖组头只改组顺序。
- [ ] **AC8** 会话拖到组头不改组。
- [ ] **AC9** 归档再恢复的项目仍在原组。
- [ ] **AC10** 删组后项目进未分组；桌面若正在看该组则回「全部」。
- [ ] **AC11** `routeDrop` 覆盖同组重排、跨组、未分组、丢自身组 no-op、会话丢组头 no-op。
- [ ] **AC12** 远程节点无组数据时不出现选择器。
- [ ] **AC13** 新桌面把 `groups` + `groupId` 打进 projects 帧；手机有组时出现选择器，过滤与分段与桌面一致；无拖、无组 CRUD。
- [ ] **AC14** 旧手机忽略新字段不崩；新手机遇旧桌面不显示选择器。
