# 项目历史资料

这里保存从旧任务记录和开发日志中迁出的设计、研究、验收与排障资料。

- `09-08-*`：迁移时尚未结束或近期相关的任务资料。
- `09-03-workspace-search/`：源码注释引用的历史设计资料。
- `archive/`：按月份归档的历史任务。
- `development-journal-*.md`：开发会话日志。

这些文件只作为历史参考，不参与开发流程，也不要求按历史任务格式继续维护。新的长期约定应写入 `AGENTS.md` 或 `docs/engineering-guidelines.md`；高代价陷阱和分层规范位于 `docs/engineering-reference/`。
